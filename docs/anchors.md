# Anker: verwendete Zotero-Interna

Alles, was Annotree an undokumentierte Zotero-Stellen hängt, mit Fundstelle (Zotero 10.0.5, `omni.ja`, entpackt aus `%LOCALAPPDATA%\Zotero\app\omni.ja`). Nach jedem Zotero-Update prüfen.

| Anker                                                                                                                                                                  | Datei (Zeilen)                                                      | Genutzt in                              |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- | --------------------------------------- |
| Aufbau des Zitierdialogs (`#annotations-sidebar`, `#annotations-list`, `#annotations-list-wrapper`, `#library-trees`, `#sidebar`, `#bubble-input`, `#includeComments`) | `integration/citationDialog.xhtml` 76–107, 195                      | `citationDialogPatch.ts`                |
| `DIALOG_STATE.loaded`, `dialog-type`-Attribut am Wurzelelement                                                                                                         | `integration/citationDialog.js` 47–54, 236–250                      | `citationDialogPatch.ts`                |
| Klick auf „+“ wird per Bubbling am Element `#annotations-list` behandelt                                                                                               | `integration/citationDialog.js` 812–818                             | `citationDialogPatch.ts`                |
| `annotation-items-pane`: Setter `items`, `render()` behält Zeilen mit Annotation in `items`, blendet gefilterte aus                                                    | `elements/annotationItemsPane.js` 33–38, 75–125                     | `citationDialogPatch.ts`                |
| Dialog wird mit `Zotero.Integration.displayDialog(url, mode, io, …)` geöffnet; `io` ist ein `CitationEditInterface`                                                    | `xpcom/integration.js` 470–495, 1594–1611, 1790–1810                | `citationDialogPatch.ts`, Test          |
| Locator-Texte brauchen `Zotero.Styles.locales`                                                                                                                         | `xpcom/cite.js` 48–54, `integration/citationDialog/helpers.mjs` 421 | Test                                    |
| Annotationen sind Kind-Items; Sammlungen werden nur für Top-Level-Items synchronisiert; Tags und Relationen synchronisieren                                            | `xpcom/data/item.js` 6112–6124                                      | Datenmodell                             |
| Fremde Annotationen in Gruppenbibliotheken sind schreibgeschützt (`Item.isEditable`)                                                                                   | `xpcom/data/item.js` 1572–1590                                      | `organizerData.ts`                      |
| `Zotero.Tags.rename` verschmilzt bei Namensgleichheit                                                                                                                  | `xpcom/data/tags.js` 283–347                                        | nicht genutzt (eigener Weg `renameTag`) |
| `Zotero.MenuManager.registerMenu`                                                                                                                                      | `xpcom/pluginAPI/menuManager.js`                                    | `utils/menu.ts`                         |

Das Plugin hängt **keine Prototypen** um; der Dialog-Patch ergänzt nur DOM-Elemente und setzt `items` am Annotationsfeld. Beim Beenden (`stop()`) werden alle Ergänzungen entfernt.
