# Anker: verwendete Zotero-Interna

Alles, was Annotree an undokumentierte Zotero-Stellen hängt, mit Fundstelle (Zotero 10.0.5, `omni.ja`, entpackt aus `%LOCALAPPDATA%\Zotero\app\omni.ja`). Nach jedem Zotero-Update prüfen.
